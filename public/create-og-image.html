🎨 ساخت تصویر پیش‌نمایش تلگرام

این ابزار تصویر PNG با کیفیت بالا برای پیش‌نمایش لینک در تلگرام می‌سازد

✅ تصویر با موفقیت دانلود شد!

📋 مراحل انجام کار

گام 1: روی دکمه "دانلود PNG" کلیک کنید
گام 2: فایل og-image.png ذخیره می‌شود
گام 3: فایل را در پوشه public/ پروژه کپی کنید
گام 4: در فایل index.html این خط را پیدا کنید:
<meta property="og:image" content="...social-card.svg" />
گام 5: آن را به این تغییر دهید:
<meta property="og:image" content="https://[your-site]/og-image.png" />
گام 6: همین کار را برای twitter:image هم انجام دهید
گام 7: Commit و Push کنید:
git add public/og-image.png index.html
git commit -m "feat: Add Open Graph image"
git push origin main
⚠️ نکته مهم: حتماً URL کامل سایت خود را در meta tag بنویسید (با https://)
مثال: https://alibexarwebtasker.vercel.app/og-image.png
